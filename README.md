# Statistical Tarot · 统计塔罗

一个可独立运行的五堆塔罗抽取与频数观察工具：保存每一笔抽取，生成可离线打开的交互报告，并把「重新抽取」「重新统计」「重新排版」分开。

Standalone five-pile tarot sampling with an auditable raw log and a self-contained HTML report. Python 3.10+, standard library only. No account, API key, model, or hosted service required.

## 先看效果

下载并解压项目后，直接打开 `examples/report.html`，即可查看合成示例，无需先安装或运行程序。

如需重新生成示例页面，在项目目录中运行：

```sh
python -m statistical_tarot render --input examples/demo-statistics.json --out demo-report
```

打开 `demo-report/page.html`。这条命令只更新页面，不进行任何抽取。示例是明确标记的人工合成数据，不来自个人问题或实际占卜。

报告包含：

- 五堆总次数及各自的预期基线。
- 牌名、元素标签（资料提供时）、次数与偏离方向。
- 桌面端默认五堆并列，完整 78 张牌同时可查；单堆可以放大查看，手机端可在牌区内横向滑动。
- 按堆、偏离程度、牌名筛选，各堆保留自己的排序与计数。
- 可展开的正逆位、标准化偏离 z、双尾 p 和 Holm 校正信息。
- 单一 HTML 文件；无外部字体、图片、追踪或网络依赖。

## 新建一次抽取

```sh
python -m statistical_tarot draw --question "本次想观察的问题" --draws 1000 --out runs/session-001
```

这条命令会开始新的随机抽取。`--out` 必须是不存在的新目录；已有目录会被拒绝。抽取次数在开始前固定，默认为 1,000，允许 1–100,000 次。

每次抽取会保存牌 ID、所属堆、牌名、正逆位和序号。完成后打开输出目录里的 `page.html`。

工具使用操作系统随机源，没有 seed、重试或补抽入口。中断后的目录和已有记录应保留；不能把中断当成换一个结果的理由。工具不会续抽或把不完整记录包装成完整报告。

## 重新统计与重新排版

从完整原始记录重新统计，并更新同目录的报告：

```sh
python -m statistical_tarot analyze --input runs/session-001
```

该命令先检查原始记录序号、牌堆对应关系、记录总数和回执中的 SHA-256。它不抽牌。

只改页面、保留统计文件：

```sh
python -m statistical_tarot render --input runs/session-001/statistics.json --out runs/session-001
```

## 抽样规则

每一次先等概率选择五堆之一，再从该堆中等概率选一张。各次独立、有放回；正逆独立各 50%。

| 堆 | 牌数 | 抽到这一堆的概率 | 单张牌概率 | 1,000 次中每张的预期次数 |
|---|---:|---:|---:|---:|
| 火 · 权杖 | 14 | 1/5 | 1/70 | 14.286 |
| 水 · 圣杯 | 14 | 1/5 | 1/70 | 14.286 |
| 风 · 宝剑 | 14 | 1/5 | 1/70 | 14.286 |
| 土 · 星币 | 14 | 1/5 | 1/70 | 14.286 |
| 大阿卡那 | 22 | 1/5 | 1/110 | 9.091 |

这是五堆等概率抽样，**不是 78 张牌等概率抽样**。每堆在 1,000 次中的预期总次数均为 200。

“位置”只表示所属牌堆，不自动赋予时间顺序、人物、事件阶段或因果角色。大阿卡那保持独立一堆；可选元素标签不改变抽样概率。

## 怎样读数字

主统计按牌名合并正逆位；每张牌的正逆次数完整保留。

- 单牌基线使用预先规定的总抽取次数和无条件单牌概率，不改用事后观察到的堆总数。
- `z = (观察次数 − 预期次数) / 标准差`。
- 接近基线：`|z| < 1`；普通偏离：`1 ≤ |z| < 2`；极端候选：`|z| ≥ 2`。这些是显示分段。
- 上下尾都包含观察值。双尾定义为 `min(1, 2 × min(P(X ≤ k), P(X ≥ k)))`，不使用按概率质量排序的另一种双尾定义。
- Holm 多重比较校正在每一堆内部单独计算，阈值为 0.05。五堆合计并未做一个统一的 78 次检验家族。
- 校正结果只作为信息显示；普通偏离、极端值和零频都保留，不删除、不平滑、不压低。

这些指标描述结果与抽样基线的距离，不能证明占卜结论的正确性，也不提供自动牌义或解读。

## 输出文件

| 文件 | 用途 |
|---|---|
| `protocol.json` | 抽取前写下的问题、次数与规则 |
| `raw.ndjson` | 每行一笔的原始抽取记录 |
| `receipt.json` | 完成状态、次数与原始文件指纹 |
| `statistics.json` | 五堆及每张牌的结构化统计 |
| `page.html` | 可离线浏览和筛选的报告 |

失败或中断时还可能留下状态信息。保留整个目录有助于辨认已经消耗的抽取和失败位置。派生的统计文件与页面可以重建；原始记录不能被自动覆盖。

## 范围与隐私

本仓库只包含程序、78 张牌的名称/标识、测试和合成示例，不附带牌义库、作者牌义文章、私人问题或沟通记录。牌表保留 `disks` / `princess` / `prince` 等既有机器标识；界面使用“星币 / 侍从 / 骑士”等中文名。

所有运行都在本机完成。报告会显示本次问题及牌面统计；分享之前请自行确认这些内容适合公开。默认输出目录与运行产物已加入 `.gitignore`，但忽略规则不能代替分享前检查。
